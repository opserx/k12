# K12 导出接口

本接口约定 `k12-export` 与其他可导出 skill 的协作方式。只有遵循此接口的 skill 才能被按其专属结构导出。

## 支持条件

一个 skill 要支持导出，必须在自己的目录中提供固定文件：

```text
references/export-template.md
```

这个文件存在即表示该 skill 支持由 `k12-export` 导出。没有该文件时，`k12-export` 不得猜测它的章节结构；应说明该 skill 尚未声明导出模板。

来源 skill 的 `SKILL.md` 还必须链接该模板，并说明只有在用户请求导出时才读取它。

## 模板契约

`references/export-template.md` 使用 Markdown，并包含：

1. 一个总标题；
2. 一个或多个章节；
3. 每个章节的标题、简短说明和应放入的实际会话内容。

模板只定义结构，不复制会话内容。章节没有对应的实际材料时省略，并在需要时说明缺失原因；绝不补造材料。

## 导出流程

1. 先判断当前会话实际使用的 skill 名称；不得仅按材料主题推测来源。
2. 对每个来源 skill 读取其 `references/export-template.md`，按模板收集已出现的材料。
3. 保留学生原文、题目、作答、反馈和版本之间的区别；同一材料重复出现时只保留一次。
4. 按用户所选模式输出：未指定时为 `chat`；明确要求时为 `pdf`。

多个来源 skill 同时导出时，分别按各自模板成组排列，并保留它们在会话中出现的顺序。
