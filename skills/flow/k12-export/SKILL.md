# Learning Session Export

## 训练目标

将当前会话中的学习过程整理为一份可打印、可直接使用的材料编排稿，使教师、家长或学生无需回看聊天记录，也能按照材料顺序使用本次学习内容。

## 适用范围

仅当用户明确要求导出、生成打印稿或整理本次练习材料时使用本 skill。导出不会开启新的写作练习，也不会改写、删减或润色学生已经提交的原文。

## 收集材料

1. 收集当前会话中实际出现、被使用或被引用的全部练习材料，包括用户（学生、教师或家长）直接提交的文字、题目与提示、错误片段、学生初稿或修改稿、点评、修改稿、最佳例文，以及为讲解所提供的必要规则说明。
2. 不要编造会话中未出现的材料，也不要把与当前练习无关的闲聊、内部推理、工具日志或敏感信息放入编排稿。
3. 保留每份材料的原有文字内容与出现顺序；如材料本身来自某一 skill，必须标明其归属。学生直接提交的文本也必须导出，并标明其在学习流程中的角色，例如“学生提交的初稿”或“学生作答”。
4. 若同一文本在会话中被重复引用，只保留一份；若后来版本已被学生或教师明确替换，则保留各版本，并清楚区分“初稿”“修改稿”等版本名称。

## 材料编排规则

1. 直接在回复中输出材料编排稿，不创建 PDF 或其他文件。
2. 首页使用能概括本次内容的总标题，并简要列出本次会话使用的 skills 和材料目录。
3. 每一份具体材料必须以明确的分页标记开始，绝不能直接接在前一份材料的末尾；同一份材料内容较长时，可以自然续接。
4. 每份材料开头使用简明标题，格式为“材料 N｜技能名称｜材料角色”。例如“材料 3｜命题练习｜学生提交的初稿”或“材料 6｜听力练习｜学生作答”。
5. 标题下方用一两句简短说明材料在当时练习中的作用，以及它属于对应 skill 的哪一环节，例如“用于让学生根据提示完成独立写作；后续将据此形成修改稿”。
6. 正文应层次清晰、适合直接打印；不得截断文字或让标题与正文难以辨认。

## 完成后的回复

材料编排完成后，回复用户：

1. 已整理的材料数量及其涵盖的 skills。
2. 直接提供完整的材料编排稿。
3. 如有无法整理的附件、图片或非文本内容，明确说明缺失的具体材料与原因；不要假装已整理。
