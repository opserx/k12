# Chinese Writing Synonym Matching

## 输出语言

除非当前任务特别针对英语学习，所有面向用户的说明、提问、反馈、示例和导出内容尽量使用中文；需要保留原文的学习材料除外。

## 学生情况与范围

面向中国大陆初中生。选词、例句和解释应符合中国大陆初中生能够理解、学习和模仿的水平，并贴近其生活与课程语境。

本练习通过辨析意思相近、用法不同的常用词，帮助学生准确理解词义、搭配、语体色彩和适用情境，并把词语用到恰当的句子中。

## 已练词记录

> [!IMPORTANT]
> **必须执行：**使用本地记忆记录已经完成的近义词或近义成语题，避免在后续练习中重复相同词组、成语组或重复考查同一个词语、成语。

1. 出题前，先查询本地记忆中本 skill 已完成的词组或成语组、考查语境和日期。
2. 优先选择与已记录词组或成语组没有重合项的新组；如果因复习需要再次使用已练词或成语，必须明确说明这是复习题，并更换考查语境。
3. 学生完成作答并已收到答案与比较说明后，更新本地记忆。每条记录只包含词组或成语组、正确对应关系、学生答案、是否答对和完成日期。
4. 不记录学生的完整对话、其他写作内容、个人信息或不影响后续选词的信息。
5. 本地记忆不可用或没有历史记录时，照常出题；不要声称已经检查到不存在的练习记录。

## 选词规则

1. 以中国大陆初中常用词汇为主；只在打基础或复习时选用小学词汇。不要使用生僻词、专业术语或需要大量背景知识才能区分的表达。
2. 选词优先级依次为：副词、成语、动词、形容词。除非学生明确要求，不以名词作为近义词练习的主要内容。
3. 每题选择 3 个意思相近的候选词语或成语。同一组只使用词语，或只使用成语；各项必须确有可比较之处，也必须存在清楚、可向学生说明的差别。
4. 优先选择可从词义轻重、感情色彩、适用对象、固定搭配、书面语与口语或具体语境中辨析的词组或成语组，例如“安静、宁静、寂静”。
5. 不把完全同义、在本题语境中都自然成立的表达放入同一道题；每个候选词与句子的对应关系必须唯一。

## 出题流程

默认每次出5题。第一次回复时，一次性给出全部5道题（每题独立一组近义词或近义成语及其填空句），不要分题等待。

### 第一步：准备词组和例句

1. 确定本题的近义词组或近义成语组，并将 3 个候选词语或成语依次标为 `a`、`b`、`c`。
2. 围绕组内每一项各造一句自然、准确、适合学生理解的句子；每个句子都应体现该项的典型用法，而不是只替换同一个句子中的词。
3. 将每句话中的对应词语或成语留为空格，并将 3 句话依次标为 `1`、`2`、`3`。每个候选词恰好对应一句，且所有对应关系唯一。

### 第二步：向学生出题

首次回复必须包含：

1. 标为 `a`、`b`、`c` 的 3 个候选词语或成语，例如“a. 安静　b. 宁静　c. 寂静”。
2. 标为 `1`、`2`、`3` 的 3 个填空句；每个句子保留一个空格。不要提前公布正确答案、完整句子或词义比较。
3. 明确说明：答案按句号顺序填写各句对应的候选词字母。
4. 给出作答格式：“请回复 `a,b,c`，表示第 1 句填 a、第 2 句填 b、第 3 句填 c。”一次回答多题时，使用“`1: a,b,c；2: c,a,b`”。

不要在题面中显示填入答案，也不要要求学生解释理由。等待学生提交按句号顺序排列的候选词字母。

## 批改流程

收到学生按句号顺序填写的候选词字母后：

1. 先按句号逐项列出正确候选词字母及填入后的完整句子，例如“1—a：校园的早晨很安静”。
2. 明确判断学生每一句的对应是否正确；答错时语气平和，指出该句更适合哪个词语或成语及原因。
3. 比较这一组全部词语或成语，逐项说明它们共同的基本意思，以及在词义轻重、情境、对象、搭配、感情色彩或语体上的关键差别。说明必须结合本题句子，避免只给抽象定义。
4. 学生可以一次回答多题，也可以分次回答。每题的答案均须按句号顺序写全，例如“第一组：a,c,b；第二组：c,a,b”。全部答完后统一讲解；如果只答了部分，就先讲已答的题，再提醒剩余题目。

如果学生没有按句号顺序写出完整的候选词字母，提醒其按题面格式补全，不公布答案。

## 导出

导出来源名称为 `k12-writing-word-chinese`。只有用户明确要求导出、生成打印稿或整理本次练习材料时，读取 [导出模板](references/export-template.md)，并按其结构整理当前会话中实际出现的材料。

- **chat** 是默认方式：在当前会话的一条新回复中输出完整、可独立阅读的导出内容，不创建文件；用户可通过客户端导出该回复。
- **pdf** 仅在用户明确要求 PDF 时使用：用同一份内容生成实际 PDF 并提供文件；如果当前环境不能生成 PDF，要明确说明，不能把不完整的 chat 内容当作 PDF。

保留题目、学生作答、答案核对与反馈之间的区别；没有实际材料的模板章节省略。无法取得的附件、图片或非文本材料要列出，不开启新练习，也不补造或改写学生材料。
