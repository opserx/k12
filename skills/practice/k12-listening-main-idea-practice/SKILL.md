# Listening Main-Idea Practice

每天练习 10–15 分钟。目标是先抓住“最重要的是什么”，而不是记住尽可能多的细节。

## 输出语言

除非当前任务特别针对英语学习，所有面向用户的说明、提问、反馈、示例和导出内容尽量使用中文；需要保留原文的学习材料除外。

使用 1–2 分钟的中文口语音频，例如新闻或课文录音。阅读文本不能替代听力；本 skill 由当前 Agent 生成并播报训练片段，不要求学生先准备录音。

## 内部语音生成与播放

在询问学生选择子练习前，先检查当前会话实际可用的工具及其 schema。不要根据对话名称、模型名称或用户自述猜测 Agent；只有能生成中文音频并把结果播放或呈现给学生时，才开始练习。

### Grok

当前会话同时提供 `voice_list_voices` 与 `voice_generate_speech` 时，将其识别为可用的 Grok 语音环境，不再每次列举或筛选声音。`voice_generate_multi_speech` 是可选的多片段工具。

默认固定使用：

- 工具：`voice_generate_speech`
- voice：`luna`
- language：`zh`
- dest_path：以 `.mp3` 结尾的工作区路径
- 不传 `with_timestamps`

`luna` 的依据已经核对，练习时不再重查：会话声音目录中其为 female、multilingual；xAI 官方描述为 gentle、patient、deeply nurturing，用途为 Education / Assistant；官方样例含中文。备选同为女性多语种柔和声的是 `carina`、`liora`、`aurora`，本练习默认仍用 `luna`，不要使用偏活泼的 `eve`。

只按这三个会话工具的实时 schema 传参。会话工具没有独立的风格、语速或 instructions 字段；需要略慢、略柔时，把 `<slow>`、`<soft>`、`[pause]` 写进 text。不得把 xAI 公共 REST API 的字段名臆造为会话工具参数；会话字段是 voice，不是 voice_id。

依照选定子练习准备未向学生展示的中文训练文本，按自然语义切成短片段。仅当有多个独立片段且 `voice_generate_multi_speech` 确实存在时才使用它；否则逐段调用 `voice_generate_speech`。每段生成后，用宿主返回的 MP3 立即播放或呈现；播放前不显示对应原文。

仅在下列情形停止并输出“当前 Agent 不能生成音频，无法进行这次听力练习。”：所需工具缺失、调用被拒绝或失败、无法把音频播放或呈现给学生。不要改成阅读理解，也不以文字模拟音频。

### ChatGPT／Codex 与 Claude Code

ChatGPT／Codex 的 Voice 是用户与 Agent 对话的界面能力，而不是本 skill 可调用的任意片段播报工具；Claude Code 的 `/voice` 是语音听写，也不是语音输出。这两类环境没有在当前会话实际暴露、且已授权的中文 TTS 与播放工具时，不得调用 API、系统朗读、插件或第三方服务作为替代。

### 不能生成时

Grok 所需工具缺失、工具调用被拒绝或失败、没有合格声音、无法播放或呈现音频，或当前环境不属于上述可用 Grok 语音环境时，直接输出：`当前 Agent 不能生成音频，无法进行这次听力练习。` 不开始子练习，不改成阅读理解，也不以文字模拟音频。

需要核对各 Agent 的语音能力、Grok 工具与 xAI 公共 API 的区别，或未来宿主出现新工具时，读取 [Agent 原生语音能力调研](references/agent-native-voice.md)。

## 选择子练习

开始一次新练习时，先让学生从以下四项中选择一项：

1. **分层练习**：按基本事实、直接行动、关注点、差异点，逐层概述听到的内容。
2. **指令过滤**：在多条口头任务中只抓必须做的一条。
3. **延迟复述**：听完等待 10 秒后再说要点。
4. **干扰听**：有轻微背景干扰时仍抓住中心句。

允许学生直接说名称或回复 `1`–`4`。选定后只进行该项，不要在一次 10–15 分钟练习中加入其他子练习。

学生暂时无法选择时，推荐分层练习并说明原因，再请他确认；不要直接开始练习。

## 子练习 1：分层练习

音频生成后、播放前，先用下面的提示告诉学生如何听：这次不用记住每一个细节，重点按四层抓信息。

1. **基本事实**：发生了什么，是整段话最基础的事情。
2. **直接行动**：听者现在需要做什么，尤其留意对象和截止时间。
3. **关注点**：说话人特别提醒、需要留意的结果、条件或时间。
4. **差异点**：和一般预期不同、值得特别揣摩的例外或额外含义。

说明完后播放音频，不预先展示原文。

音频播放结束后，告诉学生如何回答：不按原文顺序复述，也不只报关键词；每一层都用一句完整的话概述听到的内容。我会依照基本事实、直接行动、关注点、差异点的顺序逐题提问；每答完一题，再回答下一题。

依次只问一个问题，等学生回答后再问下一个；不要预先展示原文或一次列出四个问题：

1. **基本事实是什么？** 概述发生了什么，是整段话最基础的事实。
2. **直接行动是什么？** 概述听者现在需要做什么；包含必要的对象或截止时间。
3. **关注点是什么？** 概述话语特别提醒、需要留意的结果、条件或时间信息。它可以与直接行动中的时间有关，但不能只重复行动本身。
4. **差异点是什么？** 概述与一般预期不同、因而值得特别揣摩的内容，并说明它可能指向的例外或额外含义。没有明确差异点时，回答“无明显差异点”，不要杜撰。

四题回答完成后，按相同层次逐项反馈：先判断该层是否准确，再指出遗漏、混层或把普通细节误判为差异点的地方。

例如，听到以下内容：

> 为了让同学更好地适应初中生活，我们将开展为期一周的军训。因为军训比较累，如果有不参加的同学需要提前和班主任老师请假；如果确认参加也需要在班主任老师那报名。军训的表现将计入最终期末分数，明确不参加军训的同学除外。军训参加情况反馈最晚不超过明天中午。

应依次概述为：

1. **基本事实**：学校开展军训。
2. **直接行动**：明天中午前报名或请假。
3. **关注点**：表现将计入期末分数、明天中午。
4. **差异点**：明确不参加军训的同学除外；这表示不参加者不受“表现计入期末分数”这一通常安排影响。

## 子练习 2：指令过滤

由成人或可播放的口语材料连续给出 4–5 条任务，其中仅一条是必须执行或复述的指令。学生听完后只执行或复述那一条，其他内容忽略。

任务必须通过听觉给出；不要改为让学生阅读任务列表。

## 子练习 3：延迟复述

听完音频后等待 10 秒，再让学生说出要点。反馈时关注学生是否仍能抓住中心，而不是要求补回所有细节。

## 子练习 4：干扰听

在可安全控制音量的前提下，加入轻音乐或说话声背景，仍只要求学生说出中心句。

如果无法提供真实的声音环境，跳过本项；不要用文字描述模拟干扰听。

## 导出

导出来源名称为 `k12-listening-main-idea-practice`。只有用户明确要求导出、生成打印稿或整理本次练习材料时，读取 [导出模板](references/export-template.md)，并按其结构整理当前会话中实际出现的材料。

- **chat** 是默认方式：在当前会话的一条新回复中输出完整、可独立阅读的导出内容，不创建文件；用户可通过客户端导出该回复。
- **pdf** 仅在用户明确要求 PDF 时使用：用同一份内容生成实际 PDF 并提供文件；如果当前环境不能生成 PDF，要明确说明，不能把不完整的 chat 内容当作 PDF。

保留题目、学生原话、练习记录与反馈之间的区别；没有实际材料的模板章节省略。无法取得的附件、图片或非文本材料要列出，不开启新练习，也不补造或改写学生材料。
