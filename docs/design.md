# QQ Skills 设计说明

## 目标

这是为刚上初中的圈圈准备的课外辅导 Agent Skills 集合。它把会反复出现的辅导做法沉淀为小而可组合的 skills，帮助 Agent 先理解具体困难，再选择合适的辅导或练习活动，并根据实际反馈调整。

## 设计原则

- **以学习者为中心**：先理解题目、目标和当下感受；不为了形式上的效率压过真实需要。
- **一技一事**：每个 skill 只解决一个清晰的问题，避免一个“大而全”的总流程。
- **可组合**：流程 skill 负责选择与衔接，领域 skill 负责具体工作。
- **工具中立**：不假设 Claude Code、ChatGPT、Codex、特定模型或插件存在。
- **本地可修改**：skill 是普通 Git 文件；使用者自行决定何时安装、更新和修改。

## 技能分类

```text
skills/
├── flow/       # 流程、路由与跨类别协作
├── tutoring/   # 人与 Agent 一起进行的课外辅导
└── practice/   # 学习者自我练习、复盘与反馈
```

### `flow`

放置决定“下一步做什么”的流程、路由和跨类别协作技能。`ask-qq` 是当前入口：它解释本集合，并根据问题把人带到合适的 skill；以后所有与流程有关的 skills 都放在这里。

### `tutoring`

放置由家长、老师或 Agent 参与的辅导技能，例如设计一次辅导课、解释一个难点或安排互动。当前的 `lesson-planner` 是空白起步 skill，尚未定义具体方法。

### `practice`

放置学习者自己完成练习、检查结果和回顾错题的技能。当前的 `practice-review` 是空白起步 skill，尚未定义具体方法。

## 边界

分类用于发现和维护，不改变 skill 的名称，也不要求运行时支持分类。一个 skill 的实际入口始终是其目录内的 `SKILL.md`；`flow` 不替代 `tutoring` 或 `practice` 的具体方法。
