# QQ's After-School Tutoring Skills

[中文](./README.md) · [GitHub](https://github.com/opserx/k12) · [MIT License](./LICENSE)

This is a collection of skills for middle-school after-school tutoring in mainland China, published as the plugin marketplace `k12-skills`. Install the plugins you need, then invoke their skills directly in your agent.

## Source and sync

- The single source of truth is the Notion database [月树提示词](https://app.notion.com/p/3fb2b3b798a980a0be07d82401f4c36c). Each skill is a page; its `Tags` (`flow`, `practice`, `tutoring`) decide which plugin it belongs to.
- [opserx/notion-skills-github-sync](https://github.com/opserx/notion-skills-github-sync) syncs the skills hourly into `plugins/<tag>/skills/<skill>/` and updates the three marketplace manifests: `.claude-plugin/marketplace.json`, `.cursor-plugin/marketplace.json`, `.agents/plugins/marketplace.json`.
- Everything under `plugins/` is generated by the sync. Do not edit it by hand; the next sync overwrites it.

## Installation

### Claude Code

```bash
claude plugin marketplace add opserx/k12
claude plugin install flow@k12-skills
claude plugin install practice@k12-skills
claude plugin install tutoring@k12-skills
claude plugin install notion-skills-updater@k12-skills   # optional: edit skills from your agent
```

Turn on auto-update for `k12-skills` in `/plugin` → Marketplaces to receive updates automatically, or run `claude plugin update flow@k12-skills`.

### Codex

```bash
codex plugin marketplace add opserx/k12
codex plugin add flow@k12-skills
codex plugin add practice@k12-skills
codex plugin add tutoring@k12-skills
codex plugin add notion-skills-updater@k12-skills   # optional
```

### Cursor and team workspaces

Cursor (Dashboard → Plugins → Team Marketplaces → Import from Repo) and ChatGPT workspaces (Admin Console → Plugins → Import marketplace) can import `https://github.com/opserx/k12` directly.

## Plugins

| Plugin | Skills | Purpose |
| --- | --- | --- |
| `flow` | `k-12-ask-qq`, `k-12-export-enable` | Explains the collection and recommends a next step; adds internal export support to a skill. |
| `practice` | `k-12-listening-idea-practice`, `k-12-reading-deepth-english`, `k-12-writing-word-chinese` | Main-idea listening, English close reading, Chinese synonym practice. |
| `tutoring` | `k-12-writing-rewrite-chinese`, `k-12-writing-short-chinese` | Chinese revision practice, prompted fragment writing. |
| `notion-skills-updater` | `notion-skill-updater` | Writes skill edits back to Notion via the Notion MCP. |

The Notion export normalizes `k12-` in names to `k-12-`.

## Editing skills

Edit the page in Notion, or install `notion-skills-updater` and let your agent change it through the Notion MCP. Changes appear here after the next sync and reach installed agents as a new version (`1.0.0-notion.<hash>`).
