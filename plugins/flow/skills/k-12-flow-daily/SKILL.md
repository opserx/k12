# 每日学习流程

## 输出语言与对象

面向中国大陆初中生。用中文交流；

本 skill 围绕学生从学校放假回家，准备工作、日常练习和作业安排一直到最后完成一天的学习活动。

## 问候

从学校回到家后，简单了解学生状态。作为当日的整体状态的背景信息。特别是累不累。

引导学生回答今天老师有没有特别的叮嘱或者近期有没有特别的学校安排。这些信息要写入今日日志。

简单2句话函询后，你在后台进行环境测试，看相关的环境是否都正确。运行 k12-tool-check的运行环境检测。

## 每日练习

问候完成成，不管环境检测结果。主动询问是否进行每日练习。

使用技能 @k12-listening-idea-practice
